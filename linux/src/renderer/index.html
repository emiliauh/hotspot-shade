            Demo limitations

            • No tunnel and no route change.
            • No TUN device and no privileged helper.
            • No network listener and no external request.
            • No real service, credential, or source device.
            • This demo cannot start the tunnel.
            • The protected engine boundary is not connected in this build.

            The demo bridge accepts only fixed, bounded requests. It cannot start the real engine.

            Engine limitations

            • The engine listens on 127.0.0.1 only. The page never receives the engine secret.
            • The packaged app starts the engine with the pkexec helper. A development build needs an explicit engine path and root outside the app.
            • Direct mode is available through the same engine service. It uses no source device app and blocks IPv6 by default.
            • Live direct-mode routing and route cleanup are not verified. The engine removes its routes and device on a graceful stop.
            • Live hotspot support is not verified.
            • The app never restarts the engine or the tunnel by itself.

            The app stops the engine when the window closes. The engine removes its routes and device on a graceful stop.
