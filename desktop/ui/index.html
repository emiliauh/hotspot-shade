          Demo mode

          This app is a user interface demo. It uses the in-memory DemoBackend and the narrow demo_api bridge. It has no tunnel, no route change, no network listener, and no real service.

          Counters, logs, pairing steps, failures, and start and stop results are simulated. Windows and Linux tunnel support is not implemented.

          Demo limitations

          • No tunnel and no route change.
          • No network listener and no external request.
          • No real service, credential, or source device.
          • No Windows or Linux tunnel support.
          • No claim that a tunnel is on when the demo bridge is unavailable.

          The demo bridge redacts credential-like fields. It cannot start the real engine.
